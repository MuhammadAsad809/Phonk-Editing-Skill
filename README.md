# Phonk Editing Skill

> A practical, structured skill guide for creating high-energy Phonk edits with beat-synced cuts, speed ramps, controlled effects, AI-assisted workflows, and platform-ready exports.

## Overview

**Phonk Editing Skill** is a reusable reference for editors, creators, and AI-assisted editing workflows. It focuses on the decisions that make Phonk edits work: **music first, intentional pacing, controlled effects, strong drops, and clean visual hierarchy**.

The detailed editing instructions are maintained in [`SKILL.md`](./SKILL.md).

## What This Skill Covers

- Beat mapping and music-first editing
- Drop and climax synchronization
- Drift, Memphis, Brazilian, Gym/Hype, and Sigma-style workflows
- Speed ramps and velocity editing
- Camera shake, zoom pulses, and motion blur
- Glitch, VHS, grain, and chromatic effects
- Skull and graphic overlays
- Phonk-specific color grading
- CapCut, After Effects, and Alight Motion workflows
- AI video generation and enhancement workflows
- Manual + AI hybrid editing techniques
- Short-form export settings
- Common mistakes and quality-control checklists

## Core Editing Philosophy

```text
Music → Beat → Footage → Pacing → Speed → Impact Effects → Overlays → Color → Export
```

Effects are secondary to timing. If an effect hurts synchronization, subject visibility, or pacing, remove the effect.

## Supported Phonk Styles

| Style | Visual Direction | Typical Use |
|---|---|---|
| Classic Memphis | Lo-fi, VHS, grain, warm/desaturated | Retro and underground edits |
| Drift Phonk | Fast cuts, speed ramps, shake, neon contrast | Cars, drifting, street edits |
| Brazilian Phonk | Rapid montage, strobe, saturated colors | Dance, street, high-energy clips |
| Gym/Hype | Heavy impact, zoom pulses, controlled shake | Fitness, combat, motivation |
| Sigma/Meme | Freeze frames, punch-ins, text, skull graphics | Meme and character edits |

## Quick Workflow

1. Choose the track and identify the build-up and drop.
2. Mark kicks, 808s, cowbells, vocals, and major accents.
3. Select footage with usable movement and clear subjects.
4. Build the rough cut before adding effects.
5. Use speed ramps where movement supports them.
6. Add shake, zoom, blur, and glitch only on meaningful impacts.
7. Apply the appropriate color grade.
8. Add overlays and sound design without cluttering the frame.
9. Review the edit at full playback speed.
10. Export for the target platform.

## AI Editing Principle

AI should **accelerate repetitive work and generate supporting assets**, not replace creative timing decisions. Prefer real footage when it already provides the required motion. For AI-generated clips, keep one dominant camera movement per shot to reduce visual artifacts.

## Quality Checklist

Before publishing, verify:

- [ ] Cuts land naturally on the music
- [ ] The build-up has enough breathing room
- [ ] The drop contains the strongest visual event
- [ ] Speed ramps match the footage
- [ ] Shake and blur are controlled
- [ ] Glitch/VHS effects are used selectively
- [ ] Overlays do not hide the subject
- [ ] Color grading preserves useful detail
- [ ] Sound effects do not overpower the music
- [ ] Export settings match the target platform
